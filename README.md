# iot-exemplo-repositorio
Esse repositório serve de exemplo para a entrega de atividades da máteria de IoT.

Enunciado:

Vamos ligar o LED!
O projeto vai:
Utilizar um botão como entrada para controlar um LED como saída.
Ao pressionar o botão, o Arduino altera o estado do LED.
Cada clique liga ou desliga o LED, funcionando como um interruptor eletrônico.
O Arduino lê o estado do botão pelo pino 7 e controla o LED pelo pino 10.
MATERIAIS NECESSÁRIOS:
1 x Placa Arduino UNO;
1 x Cabo USB;
1 x Protoboard;
1 x Resistor de 200 Ω ou 220 Ω;
1 x Resistor de 10 kΩ;
1 x Botão tipo push button;
1 x LED vermelho difuso de 5 mm;
Fios de jumper macho-macho.
